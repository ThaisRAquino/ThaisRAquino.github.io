## 📋 Sobre

Portfólio pessoal desenvolvido para apresentar minha trajetória e projetos na área de desenvolvimento de sistemas. Une minha vivência em **análise de crédito** — lidando com documentação, dados e processos financeiros reais — com projetos que aplicam essa experiência na automação e organização desses processos.

- 🎓 Certificação **ABECIP CA-600** em crédito imobiliário
- 💻 Cursando desenvolvimento de sistemas na **UniFECAF**
- 🔧 Do backend ao frontend, aplicando o que aprendo em projetos reais

## 🚀 Como rodar localmente

```bash
git clone https://github.com/ThaisRAquino/ThaisRAquino.github.io.git
cd ThaisRAquino.github.io
# abra o index.html diretamente no navegador,
# ou sirva com um servidor local:
python -m http.server 8000
```
